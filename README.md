# Sitio personal de Vito Savoia

Sitio web personal y profesional de una página, creado a partir del CV y las fotos provistas.

## Cómo abrirlo

Abrir `index.html` en un navegador. No necesita instalación ni servidor local.

## Que editar

- Textos principales: `index.html`
- Version en ingles: `en.html`
- Estilos visuales: `styles.css`
- Interaccion del menu mobile: `script.js`
- Fotos: `assets/images/`
- CV descargable: `CV Vito Savoia.pdf`
